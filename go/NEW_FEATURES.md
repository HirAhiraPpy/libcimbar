# 新功能说明

## 已实现的功能

### 1. 开始/停止识别按钮

**位置**: 页面右上角控制区第一行

**功能**:
- **开始识别**: 启动摄像头帧捕获并发送到服务器
- **停止识别**: 停止帧捕获，节省带宽和处理资源

**自动停止**: 当文件完整解码并保存后，会自动停止识别

**状态指示器**: 页面顶部中央显示当前状态
- 🟢 **已就绪** - 摄像头和 WebSocket 已连接，等待开始
- 🔵 **扫描中** - 正在发送帧到服务器
- 🟡 **解码中** - 服务器正在解码数据
- 🔴 **已停止** - 识别已停止
- ✅ **完成** - 文件已成功保存

### 2. 摄像头分辨率选择

**位置**: 页面右上角控制区第二行

**可选分辨率**:
- 640x480 - 低分辨率，传输更快，适合网络条件差的情况
- 1280x720 - 中等分辨率，默认值，平衡质量和速度
- 1920x1080 - 高分辨率，图像更清晰，适合远距离扫描

**切换分辨率**:
1. 点击分辨率下拉菜单
2. 选择需要的分辨率
3. 摄像头会自动重新加载

**注意**: 切换分辨率会停止当前的识别过程，需要重新点击"开始识别"

### 3. 正方形裁剪

**原理**:
- Cimbar 条码是正方形（1024x1024 像素）
- 前端自动裁剪摄像头画面的中心正方形区域
- 裁剪区域会缩放到 1024x1024 后发送到服务器

**视觉反馈**:
- **黑色半透明覆盖层** - 显示实际裁剪区域
- **绿色边框** - 等待状态
- **黄色边框** - 正在扫描（服务器收到帧但没有数据）
- **青色边框** - 解码成功（服务器识别到 Cimbar）

**优势**:
- 只传输有效区域，减少带宽使用（1024x1024 vs 1280x720 全帧）
- 服务器处理更高效
- 前端统一输出尺寸，服务端无需适配多种分辨率

## 使用流程

### 快速开始

1. **打开页面**
   - 访问 https://your-domain.com
   - 允许摄像头权限

2. **选择分辨率**（可选）
   - 默认 1280x720 适合大多数场景
   - 远距离或细节多时选择 1920x1080
   - 网络慢时选择 640x480

3. **开始识别**
   - 点击"开始识别"按钮
   - 将手机摄像头对准 Cimbar 条码
   - 确保条码在裁剪框（中央方形区域）内

4. **等待完成**
   - 扫描框变色表示正在解码
   - 文件完成后自动停止
   - 显示文件名和大小

### 使用技巧

**最佳距离**: 20-30cm，条码填满裁剪框的 70-80%

**光线要求**: 充足但避免反光

**角度**: 尽量垂直于屏幕，倾斜不超过 30 度

**稳定**: 使用三脚架或支撑物保持稳定


- **响应**: 收到服务器的响应次数
- **裁剪**: 固定的裁剪尺寸 1024x1024

## 性能优化

### 带宽使用

| 分辨率 | 裁剪后 | 每帧大小 | 10fps 带宽 |
|--------|--------|----------|-----------|
| 640x480 | 1024x1024 | ~4MB | ~40MB/s |
| 1280x720 | 1024x1024 | ~4MB | ~40MB/s |
| 1920x1080 | 1024x1024 | ~4MB | ~40MB/s |

**注意**: 由于统一裁剪为 1024x1024，所有分辨率的带宽使用相同

### 推荐设置

**日常使用**: 1280x720 + 自动模式

**远距离扫描**: 1920x1080 + 模式 B

**网络条件差**: 640x480 + 模式 B

**批量传输**: 1920x1080 + 模式 Bu（如果支持）

## 故障排除

### 问题：裁剪区域太小

**解决**: 这是正常的，裁剪区域显示的是相对大小
- 实际发送到服务器的是 1024x1024 像素
- 显示大小随屏幕尺寸调整

### 问题：切换分辨率后黑屏

**解决**:
1. 等待摄像头重新加载（约 2-3 秒）
2. 如果仍然黑屏，刷新页面
3. 检查摄像头权限

### 问题：自动停止后想继续扫描

**解决**: 点击"开始识别"按钮重新开始

## 技术细节

### 前端处理流程

```
摄像头 → Canvas → 裁剪中心正方形 → 缩放到 1024x1024 → WebSocket → 服务器
```

### 裁剪算法

```javascript
// 计算中心裁剪区域
const size = Math.min(videoWidth, videoHeight);
const offsetX = (videoWidth - size) / 2;
const offsetY = (videoHeight - size) / 2;

// 裁剪并缩放到 1024x1024
cropCtx.drawImage(
  canvas,
  offsetX, offsetY, size, size,  // 源（中心正方形）
  0, 0, 1０24, 1024              // 目标（固定尺寸）
);
```

### 服务器接收

服务器接收到的始终是 1024x1024 RGBA 图像：
- 宽度：1024
- 高度：1024
- 格式：RGBA (4)
- 数据大小：1024 × 1024 × 4 = 4,194,304 字节
